우렁각시 — 처음 실행 안내
==========================

한글(HWPX) 문서의 값을 엑셀(XLSX) 취합표 빈칸에 채워 주는 프로그램입니다.
설치하지 않고 이 폴더에서 바로 실행합니다. 관리자 권한, 인터넷, 한글, Excel이 필요 없습니다.


안전하게 만든 부분
------------------
- 원본 HWPX, XLSX는 바꾸지 않습니다. 결과는 취합표 옆에 새 파일로만 저장합니다.
- 인터넷으로 아무것도 보내지 않습니다.
- 동작하는 시험판입니다. 합성(가짜) 자료로 검증했으니 실제 업무 문서의 결과는 직접 확인해 주세요.


완전히 지우기
-------------
이 폴더를 지운 뒤, 프로그램이 이 PC에 남긴 두 가지도 지웁니다(쓴 적이 없으면 없습니다).
- 저장한 작업 규칙과 요청 문장: %LOCALAPPDATA%\ureonggaksi 폴더
- [로컬 AI 지정]으로 고른 파일 경로: 레지스트리 HKCU\Software\ureonggaksi
  (PowerShell: Remove-Item -Recurse "HKCU:\Software\ureonggaksi")
결과 XLSX, 확인필요, 근거 파일은 저장한 폴더에 있습니다.
파일을 고를 때 쓰는 Windows 대화상자는 다른 프로그램처럼 최근 항목 기록을 남길 수 있습니다.


1. 실행하기
-----------
Ureonggaksi.exe 를 두 번 누릅니다.

"Windows의 PC 보호" 파란 창이 뜨면: [추가 정보] → [실행]을 누릅니다.
(코드 서명 인증서가 없는 개인 프로젝트라 처음 한 번 나오는 경고입니다.)


2. 3분 체험 (예시 자료 사용)
----------------------------
examples\demo 폴더에 가짜 자료가 있습니다.

  1) [원본 추가] → examples\demo\이수확인서_*.hwpx 세 개를 고릅니다.
  2) [취합표 선택] → examples\demo\교육이수현황.xlsx 를 고릅니다.
  3) 요청 칸에 입력:  발급번호 기준으로 신청인이랑 생일, 이수시간 채워줘
  4) [미리보기] → 채울 칸, '확인 필요', '직접 처리할 칸'을 확인합니다.
       - 이수시간: 열 이름이 같아 바로 채웁니다.
       - 신청인 ← 문서 '성명', 생일 ← 문서 '생년월일': 이름이 달라 '확인 필요'로 보입니다.
       - A-003 행의 이수시간: 이미 다른 값이 있어 덮어쓰지 않고 '직접 처리'로 남깁니다.
  5) [저장] → [결과 폴더 열기]. 새 XLSX, '_확인필요.txt', 근거 JSON이 생깁니다. 원본은 그대로입니다.

예시 자료를 바꿔 보고 싶으면 examples\demo 폴더를 다른 곳에 복사해서 쓰세요.


3. 로컬 AI 켜기 (선택)
----------------------
AI 없이도 열 이름이 같은 항목은 채웁니다. 이름이 다른 짝("성명" → "신청인")을 더 많이 찾거나
말투가 섞인 요청을 읽으려면 로컬 모델을 켭니다. 모델도 이 PC에서만 돌고 인터넷을 쓰지 않습니다.

  1) llama.cpp 실행 파일: https://github.com/ggml-org/llama.cpp/releases
     Windows용 CPU zip(win-cpu-x64)을 받아 풀고, 그 안의 llama-completion.exe 를 씁니다.
  2) 모델(약 2.7GB): Qwen3.5-4B 의 Q4_K_M GGUF 파일 (Apache-2.0)
  3) 프로그램의 [로컬 AI 지정]에서 두 파일을 고릅니다.

모델을 쓰는 요청은 시험한 PC(8스레드 CPU, 메모리 16GB)에서 20~30초 걸렸습니다.
4코어 이하나 메모리 8GB 미만 PC는 시험하지 않았습니다.
