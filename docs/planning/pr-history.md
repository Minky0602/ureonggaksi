## 5. 검증 지표의 흐름

평가셋은 모두 합성 자료다. 처음 여는 held-out 셋의 결과만 `실측`이고, 한 번 연 셋으로 다시 잰 값은 `참고`다.

| 날짜 | 시점 | 평가셋 | 결과 | 구분 |
|---|---|---|---|---|
| 2026-11-12 | S01, 모델이 선택 전체를 작성 | s01(24) | 4B 완전 일치 3/24 | 실측 |
| 2026-11-17 | #19 병합 직후 | s01b(40) | 규칙 완전 일치 32%, 질문 정확도 82% | 실측 |
| 2026-11-20 | #20 병합 직후 | s01c(40) | S1 0, S2 0/12. C는 기준 미달, D 37.3초도 기준(30초) 초과 | 실측 |
| 2026-11-23 | #37 | s01c | S1 0, C 25% / 52% | 참고 |
| 2026-11-24 | #40 병합 직후 | s02(40) | S1 0, S2 0/12, C 17% / 37% | 실측 |
| 2026-11-25 | #44 | s01c / s02 | S1 0, C 55% / 70%(s01c), 18% / 42%(s02), D 중앙값(키 답변 뒤) 22.7초 / 13.8초 | 참고 |

- S1(표시 없이 틀린 칸)은 s01c, s02 측정에서 0을 유지했다. 다만 #40 검수에서 평가셋에 없던 S1 위반 경로가 main에서 발견되어 고쳤다.
- s01c와 s02의 차이(53% → 17%, 같은 코드)는 본 자료를 보며 고친 점수가 부푼다는 실측이다.
- 측정은 개발 PC 한 대에서 했다. 사무용 PC 값은 없다.
